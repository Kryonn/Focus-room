# Focus Room

Focus Room is a web application designed to help users stay focused and organized while studying or working.

The application provides a customizable workspace with tools such as a task board, notes and pomodoro timer.

🌐 **Live application:** [www.focusroom.com.br](https://www.focusroom.com.br)

## 🛠️ Stack

### Frontend

* React
* Vite
* JavaScript
* GridStack

### Backend

* Node.js
* Express
* PostgreSQL
* Supabase
* JWT
* Resend
